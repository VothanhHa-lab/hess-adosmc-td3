# Manuscript sources (IEEE Access format)

`main.tex` is the manuscript in the IEEE Access LaTeX template. The section files `sec_*.tex`, the tables
`tab_*.tex` and the number macros `numbers*.tex` are shared with the scripts: `numbers*.tex` and most
`tab_*.tex` are generated by `scripts/make_*.py` (see the repository README); no result number is typed by hand.
Figures are read from `../results/figures/`; the author photo is `figures/author_vothanhha.png`.

## Template files (not included)

The IEEE Access class, its style files, logos and the licensed Formata/Giovanni/Times font files are **not**
redistributed in this repository. Download the official IEEE Access LaTeX template from the IEEE Author Center
(https://ieeeaccess.ieee.org/guide-for-authors/preparing-your-article/) and copy these files from it into this
folder:

```
ieeeaccess.cls  IEEEtran.cls  IEEEtran.bst  spotcolor.sty
bullet.png  logo.png  notaglinelogo.png
t1*.pfb  t1*.tfm  t1*.fd  t1*.map
```

The manuscript was built with the template release of 13 May 2026.

## Build

```bash
cd paper
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

`main.tex` redefines the template's spot colour `accessblue` as the equivalent process colour so that titles,
headings and caption labels display in every PDF viewer.
